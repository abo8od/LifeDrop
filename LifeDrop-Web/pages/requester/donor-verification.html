System Limitation

The backend API requires DonorUserId to verify a donor (POST /api/Donors/verify). However, the request details data only provides AcceptanceId and basic contact info, missing the required user ID.

Regulatory Requirement

Verification must be completed within 30 minutes of donation to ensure unit chain of custody.
